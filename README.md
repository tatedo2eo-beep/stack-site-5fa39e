# Joe's Stack (placeholder name): public recipe site

> **TEST DEPLOYMENT.** This GitHub Pages link is for review only. Pages is set to `noindex` and `robots.txt` disallows crawling.
> GitHub Pages is **not for commercial use** (no ads, no payments here). Before ads and payments go live, the site moves to **Cloudflare Pages** on its own domain.

Static multi-page site (one real HTML page per recipe, category and section) generated by a Node build script from recipe JSON.

## Commands
```bash
npm install                 # once (esbuild + sharp)
npm run validate            # check every recipe in content/recipes/
npm run build               # build into docs/ (served by GitHub Pages)
npm test                    # rule tests (healthy labels, diet tags, allergens)
./publish.sh "Add recipes"  # validate + build + commit + push in one go
```

## Adding recipes
1. Drop `content/recipes/<slug>.json` (schema: see `src/lib/rules.js` `validate()`), photo optional in `content/images/` (any size; the build makes 600/1200 px WebP ≤ 120 KB).
2. `./publish.sh`. Errors stop the build; warnings (allergen hints, removed diet tags) are printed.

High Protein, WHO Healthy, allergens (EU 14) and diet tags are computed or checked by the build (`src/lib/rules.js`); nothing is tagged by hand.

## Config
`site.config.js`: brand name, URLs/base path, `noindex` (flip to `false` at launch), contact email, themes, locales.
i18n: UI strings live in `i18n/en.js`; add `ar.js` (dir `rtl`) or `es.js` and list them in `locales`.

## Layout
- `src/build.js`: build; `src/templates/`: page templates; `src/assets/`: CSS and JS (minified, hashed)
- `content/pages/`: about, contact, legal drafts, login placeholder
- `static/hero/frames/`: home scroll animation frames (AI-generated)
- `docs/`: built output (committed; GitHub Pages serves it)
